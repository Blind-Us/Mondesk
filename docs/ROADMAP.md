# Mondesk 現況與待辦

更新日期：2026-11-15。上一版（2026-11-14）列出的待辦已逐項處理；這份寫的是做完之後的狀態，以及哪些只能靠實機驗收。

## 定位

「桌面副螢幕資訊中心＋會根據事件反應的角色夥伴」。目前是**穩定示範版**：沒有金鑰、沒有設備也能展示完整流程（`--demo`），自動檢查一個指令跑完（`tools/check.py`）。還不是「陌生人下載就一定能用」的版本，差的是第 4 節那些實機驗收。

## 3. 這次發現、值得知道的事

- **這台電腦的系統播放資訊走的是慢速備援**：winrt 套件被 Windows 的應用程式控制原則封鎖，Mondesk 改用 PowerShell 讀取。擴充功能提供的歌詞與影片不受影響；診斷頁會顯示這件事。
- **Open-Meteo 的預報主機從這個網路連不上**（地名搜尋那台是通的），所以實際上是由挪威氣象局提供資料：沒有降雨機率百分比，「快下雨」改用預報雨量判斷。
- **Claude 官方用量**：登入過期時會自動用 refresh token 更新；這段只用模擬資料測過，還沒對真的帳號跑過。

## 4. 還沒做、或只能實機確認的

| 項目 | 為什麼還沒 |
|---|---|
| 媒體長時間播放、換來源、關分頁（ACCEPTANCE 第 1 節） | 需要真的 Chrome、擴充功能與 Apple Music／YouTube |
| 列印機事件與直播（第 2 節） | 需要真的列印機 |
| 全新 Windows 安裝、Linux（第 4 節） | 需要乾淨的機器；Linux 完全沒有驗證過 |
| 免 Python 的安裝程式 | 目前是原始碼 zip＋啟動檔，需要先裝 Python 3.10 以上 |
| 列印機控制（暫停／停止） | 刻意維持關閉，未驗證前不列為功能 |
| 角色表情圖的生成與三種一致性作法的比較 | 期末專案的圖像生成部分，要由你實際生成與評分（流程在 COMPANION.md） |
| Claude／Ollama 大腦的評估 | `companion_eval.py --brains …` 已支援，但會花 API 費用，沒有代跑 |
